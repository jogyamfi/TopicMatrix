Software Requirements Specification (SRS)
Project Title: Subject Mastery & Study Competency Tracking System
1. Executive Summary & Goals
The objective of this application is to allow users to structure subjects into specific topics, track their study progress, test their recall against past/practice questions, and schedule automated periodic reviews (spaced repetition) to ensure long-term retention.
2. User Roles & Personas
•	Learner / Student: Primary user who creates subjects, inputs practice questions, records attempts/confidence scores, and receives review reminders.
•	System (Automated): Calculates review intervals, tracks performance analytics, and pushes notifications.
* Simple user login system stored in database. Admin ability to create users.
3. Key Functional Requirements
3.1 Subject & Topic Structure Management
•	The user must be able to create, edit, rename, and delete Subjects (e.g., Mathematics, Organic Chemistry, Constitutional Law).
•	Within each Subject, the user must be able to create hierarchical Topics / Sub-topics or tag content flexibly.
•	Each Topic should display a summary status (e.g., Not Started, In Progress, Needs Review, Mastered).
3.2 Subject Competency Tracking
•	Users can add the results of a quiz session to a sub topic. 
•	This data point will include Date, Source / Year of question/ Number of questions / Number solved correctly, Confidence tracking (•  1 = Guessing 
•  2 = Somewhat know it 
•  3 = Mostly know it 
•  4 = Strong understanding 
•  5 = Expert level confidence
)


•FR-3.2 Scheduling Algorithm:
o	Uses a spaced repetition algorithm (e.g., SuperMemo SM-2 or FSRS) to automatically calculate the next review date based on the user's score.
o	Supports Custom Scheduling Intervals set manually by the user (e.g., Review after 1 day, 3 days, 7 days, 14 days, 30 days).
•	FR-3.3 Custom Study Sessions:
o	Ability to launch a quick review session filtered by:
	Subject or Topic
	Sub Topics to work on due today
	Weakest questions/topics (lowest score history)
3.4 Progress Analytics & Dashboard
•	FR-4.1 Mastery Level Indicator: Visual representation (bar chart, heat map, or radar chart) showing mastery score per topic/subject based on question accuracy history.
•	FR-4.2 Review Queue: Daily dashboard showing questions/topics scheduled for review today, upcoming, or overdue.
•	FR-4.3 Streak & Activity Tracking: Displays study frequency, questions answered per day/week, and total study time.
